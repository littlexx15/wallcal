WallCal 卸载与恢复说明

本软件是绿色版，没有安装到系统程序目录，也不需要专用卸载器。

1. 如需留档，在“导出 / 备份”中备份全部数据。
2. 打开“显示设置”，点击“停止更新并恢复原壁纸”。
   若提示无备份，停止更新后到 Windows 设置→个性化→背景中选择图片。
3. 关闭主窗口中的“开机启动”开关。
4. 点击主界面的“退出”彻底退出程序。只点窗口右上角 X 可能仍在托盘运行。
5. 删除下载的 WallCal exe、解压目录、压缩包和自行创建的快捷方式即可。

数据清理（可选）：
按 Win+R 输入 %APPDATA%\WallCal 可查看事项、主题图片和原壁纸备份。保留该目录可在以后重新使用时继续读取数据。
若要彻底删除，请先备份事项，并将需要的 original_background 图片复制到独立文件夹，在 Windows 个性化设置中改用该副本，再删除 WallCal 数据目录。否则删除恢复图片后可能影响 Windows 后续加载壁纸。
若启用过 GitHub 云同步，本地卸载不会删除云端 Gist；需要时在自己的 GitHub 账号中单独管理。
